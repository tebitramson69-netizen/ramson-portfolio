#04211A · on accent

The accent discipline rule. The accent appears on at most three elements per viewport. Permitted: the primary button, the availability dot, a link underline on hover, a focus ring, the active nav indicator. Forbidden: accent headings, accent gradients, accent card borders by default, accent icons everywhere. Scarcity is what makes it read as intentional — and this is the rule most likely to be violated under pressure.

.t-prose — body at 1rem · 1.65 · capped at 68ch

Small appointment-based businesses coordinate with customers through the messaging app both sides already use. But that conversation is not connected to any booking system, so appointments are recorded by hand and a missed message is a lost booking.

The measure is capped at 68 characters, which is what keeps long-form case-study prose readable rather than sprawling across the full container width.

Display type takes tighter tracking and leading than browser defaults give it. Loose display type is the most common reason a heading looks amateur. Weights are limited to three — 400 body, 500 UI, 600 headings — and the display serif is never set above 400.

06

Portrait

Fallback state — renders when the CMS holds no photo

A rectangular 4:5 editorial frame at 4px radius — never a circle. Circular avatars read as social-media profile pictures; this reads as a magazine feature. A hairline border offset 16px down-right sits behind it, giving depth with no shadow and no glow. The uploaded photo receives slight desaturation and a 4% accent tint so that any photograph harmonises with the palette — which matters because the image is CMS-managed and unknown at design time.

07

Form fields

So I can reply to you directly.

Labels are always visible above the field — never placeholder-as-label, which disappears on focus and fails accessibility. Inputs are set at exactly 16px, because anything smaller makes iOS Safari zoom on focus.

08

Pending state

Awaiting content

What this component is for

A designed empty state for content that has not been supplied yet. Deliberately unmistakable, so nothing placeholder can reach production by accident, and every instance names exactly what is needed.

03-OPEN-QUESTIONS · reference

This is the mechanism that keeps the content-integrity rule enforceable. Rather than inventing services, a process or project details to fill the layout, each gap renders this component and names the question it is waiting on. In Phase 7 it becomes the CMS empty state.

09

Radii & motion

--radius-sm · 4px
--radius-md · 6px
--radius-lg · 10px
--radius-full · dot only

Radii are restrained by rule: cards, images, buttons and inputs at 6px; the portrait frame at 4px. --radius-full is permitted only on the availability dot and avatar thumbnails — no 24px blobs, no pill-shaped buttons. Motion animates opacity, transform, colour and border-colour only. Scroll reveals fire once and are then unobserved, and all motion is disabled under prefers-reduced-motion.
